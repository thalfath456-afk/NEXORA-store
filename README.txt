NEXORA v7 — أسعار Free Fire
التحديثات:
- إضافة أسعار البيع المعتمدة مبدئياً لخمسة عروض Free Fire في واجهة العميل.
- إظهار سعر الباقة بعد اختيارها وإضافته إلى رسالة واتساب.
- تحديث لوحة الإدارة بتكاليف شراء ZoolPlay وأسعار البيع المقترحة وحساب الربح قبل الرسوم.
- أسعار العضوية الأسبوعية والشهرية لم تعتمد للبيع بعد؛ تظهر في واجهة العميل كـ"يرجى تأكيد السعر".
- أسعار PUBG لم تتغير ولم تُعرض كقائمة أسعار مؤكدة؛ تحتاج مراجعة منفصلة.

مهم:
- الربح في لوحة الإدارة قبل أي رسوم تحويل أو رسوم إضافية.
- هذه نسخة محلية تجريبية. لا يوجد خادم أو قاعدة بيانات مشتركة أو حفظ طلبات مركزي أو تحقق دفع أو شحن تلقائي.
- زر الطلب يفتح واتساب فقط.
- لا تحوّل أي مبلغ قبل تأكيد السعر والتفاصيل مع المتجر وبإشراف ولي الأمر.
- لا تشارك كلمات مرور أو رموز تحقق أو بيانات دخول.

\nإصدار v8 — بيانات الدفع والإيصال:
- عرض بيانات حساب بنكك وماي كاشي للعميل.
- عرض بيانات الحساب المختار ضمن رسالة واتساب.
- إضافة اختيار صورة إيصال الدفع، مع تنبيه العميل إلى إرفاق الصورة يدوياً داخل واتساب.
- لا يتم رفع أو تخزين صورة الإيصال داخل الموقع.
- تأكد من أن لديك إذناً باستخدام بيانات الحسابات وأسماء أصحابها، وأنها صحيحة قبل نشر الموقع.

إصدار v8.1: إصلاح خطأ JavaScript كان يمنع تشغيل قائمة الباقات بعد اختيار اللعبة.


إصدار v9 — أسعار PUBG Mobile:
- تمت إضافة أسعار البيع المعتمدة مبدئياً لست باقات PUBG Mobile.
- 60 UC: 10,475 SDG
- 325 UC: 51,375 SDG
- 660 UC: 104,750 SDG
- 1800 UC: 262,000 SDG
- 3850 UC: 524,000 SDG
- 8100 UC: 1,047,500 SDG
- لوحة الإدارة تتضمن تكاليف الشراء وأسعار البيع والأرباح المتوقعة.
- الأرباح قبل رسوم التحويل، والأسعار تحتاج مراجعة دورية.
- هذه نسخة محلية تجريبية وليست نظام دفع أو شحن تلقائي.


إصدار v10 — تحسين وضوح السعر وبيانات الدفع:
- تكبير السعر وإبرازه داخل مربع واضح بلون مميز.
- تكبير أرقام حساب بنكك وماي كاشي وأسماء أصحاب الحسابات.
- إضافة زر مستقل لنسخ رقم بنكك وزر لنسخ رقم ماي كاشي.
- تظهر رسالة تأكيد بعد النسخ.
- قد يتطلب النسخ السماح للمتصفح بالوصول إلى الحافظة؛ إذا تعذر، يمكن الضغط مطولاً على الرقم ونسخه يدوياً.
- بقية خصائص النسخة السابقة كما هي، بما فيها إرسال الطلب عبر واتساب يدوياً.
